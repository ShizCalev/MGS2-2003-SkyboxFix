# Metal Gear Solid 2 - 2003 PC / GOG Version Skybox Fix


- Restores all the skybox models broken in the 2003 PC / Substance version of MGS2 using the fix made by cipherxof / triggerhappy for MGSHDFix.

## Installation

- Make sure [V's Fix](https://github.com/VFansss/mgs2-v-s-fix) is installed!
- Grab the latest release of MGS2-2003-SkyboxFix from [here.](https://github.com/Afevis/MGS2-2003-SkyboxFix/releases)
- Extract the contents of the release zip into the game's scripts folder.<br />(e.g. "**Metal Gear Solid 2 Substance\bin\scripts**" for Steam).
